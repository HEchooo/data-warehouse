# Ever Pretty 视频每日数据踩坑记录

## 同名旧账号不能混入固定账号名单

2026-10-12 核验时，`dim_video` 同时有 Viviana Ricci 的 `viviana_ricci` 与 `leo_s_little_world`，旧号在9月30日以后仍有数据。Echo Matrix 当前绑定已换到后者。按名称筛选会混入旧号；应固定 `channel + creator_id`。

## 每天有 state 行不等于每天真实采集

目标视频在9月30日以来的日状态数多于真实采集快照数。state会沿用旧值且在首次采集前补零，直接展示会误报零播放。用 snapshot 标出真实采集日，首采前指标保持 NULL；相邻记录增量不用于声称缺采期间的真实逐日增长。

## 新视频可能只有 tag 占位

核验发现3条10月11日 YouTube 视频只有正式号tag，标题、链接、账号展示字段均空，发布时间等于tag时间。需要标记“待平台回流”，不能把tag时间称为准确发布时间。

## 趋势图避免把缺采画成真实零增长

累计曲线按同日视频汇总；增量柱使用 `SUM(IF(has_snapshot, view_increment, NULL))`，当日全部缺采时为空，而不是补零。旁边展示当天采集视频数，辅助判断部分采集的覆盖情况。首次回流会抬高累计曲线但没有增量基线，因此累计变化不一定等于增量柱；缺采后的差值可能跨多天。

Superset 更新 dataset 的 `columns` 会替换完整列列表，新增计算展示列必须保留现有物理列和定义，回查列数与源字段；不能只发送新增列。
