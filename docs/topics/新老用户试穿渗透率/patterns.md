# 新老用户试穿渗透率经验

## 独立 dashboard 要独立建 topic

- 这次 `【AI-Fashion】新老用户试穿渗透率` 虽然口径上复用了“平台整体内容表现”的 `试穿 UV` 定义，但资产形态已经是独立 dashboard
- 因此主题文档应独立落到 `docs/topics/新老用户试穿渗透率/`，不要继续挂在 `平台整体内容表现/fact.md`
- 判断主题归属时，优先看报表主题和 dashboard 边界，再看是否复用已有指标口径

## 多版本展开不回对总 UV

- 当报表按 `prop_app_version` 展开，且业务允许同一用户同一天命中多个完整版本号时，不要强行给用户归一个“唯一版本”
- 正确做法是先沉 `dt × user_id × app_version` 的中层事实，再在 ADS 按版本聚合
- 这样按版本汇总后的 `dau_uv / tryon_uv` 之和默认会大于主题总 UV；这是业务选择导致的结果，不是去重错误
